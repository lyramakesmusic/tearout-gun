## Machine gun preset (Phase Plant)
- **LFO → oscillator "sync" (pitch-like)** = the "attack"/movement per hit [captions: "one of the LFOs that attacks the sync, which is pretty much a pitch"].
- **Ladder filter** ("dirty filter").
- **Kilohearts EQ ("Carve EQ"?)** to remove dirty low end [captions "coffee cube"; inferred EQ].
- Distortion → **Convolver** ("gives it a nice little tone") → **Reverb** → **Multipass with OTT** ("does a lot already"; "compression is absolute magic, more powerful than any distortion") → second Multipass (lighter) → **Delay** → **Shaper** (more distortion). Automation on a param; LFO length change transforms sound.

## Reese preset (technique transferable to gun bodies)
- Phase Plant "Spec Sub" wavetable + filter (LP; add highs later via FX/compression).
- Second WT (saw) detuned against it for reese beating; OTT.
- Multipass: **convolver kept very short** ("metallic character") → **delay** ("even more metallic", tiny release) → second **convolver only on mid band 250 Hz–3 kHz** ("don't affect the sub") → **phase distortion** → distortion → OTT.

## Principle
- Multipass band-splitting: process mids (~**250 Hz–3 kHz**) hard, leave sub band clean.
