# 3ZNN60bTfT4 — "HOW TO ACTUALLY LAYER YOUR TEAROUT BASSES" — BassTi (8:22)

Ableton; layering philosophy, response to oddprophet. Few numbers.

## Body
- Main layer: **Phase Plant granular** generator loaded with a very long resampled sound-design file (Hyper/Dimension, Wide Riddim-style FX); "Basack" rack (Nasko), **phase distortion, ring mod, convolvers, filters, disperser, Fatator**.
- Variation: skip grain position through the long file → each hit different. Second half of drop: **change the LFO inside the Phase Plant patch**.

## Transient
- Dedicated **snappy transient layer** using "**Thorn**" device (free, transient shaper with more punch/sharper).

## Spice
- **Collision** (Ableton physical-model mallet/resonator synth) as a layer — "Corpus as a synth" (trick credited to Akuma): adds tonal character/depth.
- Noisy high-end layer for energy; resampled snippets with processing; Serum patch of sines through **"Reese" filter**, **staircase LFOs** on pitch/coarse octaves, frequency shifter, disperser.
- A stretched texture layer **gated** by the main patch (follows its rhythm).

## Group
- Compression on group; EQ each layer to avoid overlaps: roles = transient / tonal / texture-noise / main.
