# Zcx64R68uoc — "HOW TO MACHINE GUN BASSES (SVDDEN DEATH, CODE: PANDORUM, ETC.)" — Rocket Powered Sound (7:07)

Serum. Envelope (not LFO) gated per MIDI note; double comb.

## Body
- Noise osc level ~**72** (lots of noise).
- Osc A: **"Creeper"** wavetable (Spectral folder) — grimy, vocal.
- Osc B: **square** (Basic Shapes), low level.
- Filter **comb**: cutoff left at ~**425 Hz**, resonance **~98**, drive cranked, **damping up** to correct tone; osc B routed too.

## Envelope / pattern
- **Env 1 (amp)**: attack default (0), **sustain -inf**, **decay ~115 ms**, release untouched. "This is how we created the machine gun effect" — note-drawn, **no LFO**; rhythm comes from MIDI notes.

## FX (Serum)
- Distortion **Tube, mix 50%** (parallel half-dry "fuller").
- FX filter: **second comb**, resonance up.
- **Phaser with rate 0, depth 0, freq 0**, a little feedback = static "guitar-type" comb-ish coloration.
- Hyper (detune a bit, mix up), multiband compressor (threshold to taste).
- **Delay short, unsynced ~15 ms**, linked, mix up — "metallic tone".
