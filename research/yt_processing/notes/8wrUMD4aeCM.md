# 8wrUMD4aeCM — MAKING HEAVY DUBSTEP BY RESAMPLING (Swampy, 8:11)

**Relevance:** High for resampling workflow; few numbers.

## Chain
1. **Record a whole drop, apply tape-stop (Edison)** → "mud pies"; pick tiny snippets and loop them as new bass hits.
2. Processing snippets: **Disperser** → **Multipass Phase Distortion (tone up, drive up)** → Frequency Shifter → Dimension Expander → remove low end → Flanger slow rate → Ring Mod → **"band 3" up then distort** → (oddprophet method) shift up.
3. Gun: macro on mix; offset eighth notes; add a transient sample on each hit.
4. **Fake-out trick:** Multipass with high band gain up, low band gain all the way down → frequency shift up a bit → bitcrush → automate Multipass mix.
5. Drums: soft clip on drum bus; sidechained top-drums bus.
