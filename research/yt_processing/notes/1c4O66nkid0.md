# 1c4O66nkid0 — How To Make A EASY PHAT RACK/Effect CHAIN (Dubstep, CLEAN) (Dripment, 10:03)

**Relevance:** High. Explicit numeric "loud rack" for dubstep basses (Ableton).

## Chain (in order)
0. Optional **Corpus** (pipe mode, tuned to song key note D0, decay ≈ 429 automated) placed *before* the loud rack — "signal flow is important".
1. **OTT #1:** output +6 dB, amount 100%, time 1000%.
2. **Saturator #1:** drive +5 dB, Analog Clip curve, soft clip ON (clip at 0 dBFS).
3. **OTT #2:** identical settings.
4. **Saturator #2:** drive +6 dB ("66db" caption), soft clip ON. Claims perceived loudness rise is mostly brightening; meter stays about −10/−9 at this point.
5. **EQ Eight:** boost around 100–200 Hz.
6. **Glue Compressor:** attack 0 (0.01 ms), threshold −10 dB, makeup +4 dB.
7. (In-song) Reverb + another EQ (boosts, low cut) — reverb supplies width.
8. **JST Clip (hard clipper) last**, ~−5 dB of clip ("with this clipper at negative five we're getting very loud"), 2× oversampling on. Later set to clip at 0.
- Target bass/track loudness: around −4 to −3 LUFS ("negative two is extremely ear piercing").
- **Width layer:** duplicate patch → same rack → M/S EQ removing all Mid → Haas ("easy sides") + Acon Multiply chorus → side-only layer under mono main.

DSP: (3-band up/down comp → soft-clip) ×2 → low-shelf/peak 100–200 Hz → fast VCA comp 0 ms attack → oversampled hard clip.
