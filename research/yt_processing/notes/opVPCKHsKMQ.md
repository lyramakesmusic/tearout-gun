## A. "Tail dog" resample
1. Resample growl group to new audio track (turn **sidechain off** while recording, else gaps).
2. Cut just the tail of the growl; fade in.
3. Warp mode **Texture**, transpose **−12 st**, tweak grain size (only works when transposed). Layer with other basses → "evil" dark bass.
   - DSP: granular time-stretch with pitch-shift down an octave; grain-size sets roughness.

## B. Growl post rack (order as shown, read end→start in the video)
Mid/side parallel: mono (mid) path dry-ish, side path gets stereo FX.
1. **OTT** depth **32%**, output gain **+12** (dB).
2. **Amp** (Ableton Amp) heavy distortion, **Dual** mono/stereo mode (more stereo), **dry/wet 37%**.
3. Stereo FX on side signal (unspecified).
4. **EQ**: boost mids, cut lows.
5. **GClip** (JST/"jsd clip") at **0 dBFS** ceiling — last.

## C. Serum growl patch
- Osc A: basic shape **square**, **FM from B 56%**, LFO ramp (rate **1 bar**, trigger) → osc level up full.
- Osc B: **"Monster 6"** wavetable, **WT pos 128**, level down; warp **Sync (no window)** at **9.09**, mod past halfway — sync raises pitch while FM is active.
- Filter: **Flanger −** type; LFO→cutoff base **218** (Hz) +30; resonance **16** −67; drive 0 +48 (LFO); mix 0 +75 → push-pull movement.
- Sub level 0, LFO +45.
- FX: **Distortion Diode 1** drive 0 LFO→+100, mix 100 → **Phaser** rate 0.01, depth 66, freq **869 Hz**, feedback 72 → **Compressor multiband** gain **9.2**, threshold **−13 dB** → **Reverb Hall** size 24, decay 2.5 s, mix 0 + LFO 41, low cut 0, high cut 35% → **Filter Comb**, cutoff **7149 Hz**, res 0%, LFO +19, drive 35%.
  - DSP: diode-clipper → phaser (allpass notch comb around 869 Hz) → 3-band upward/downward comp → LFO-gated reverb → comb at 7.1 kHz.
