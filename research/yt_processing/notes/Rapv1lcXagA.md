# Rapv1lcXagA — HOW TO MAKE TEAROUT DUBSTEP LIKE NIMDA
Swampy · 17:46 · FL Studio + Serum, Kilohearts

**Relevance:** High. Full chain listings for tearout gun, sustain, snare-gun and resamples; mostly orders, few numbers.

## Fake-out bass
Serum: Osc A = bass loop dragged in as wavetable, LFO1→WT pos; Osc B FM into A (B level down), macro automates B octave; **Serum distortion cranked**. Post: **Disperser → Disperser → Dimension Expander → Multipass → OTT → EQ** (EQ boosts "screamy" frequencies) → automated reverb → EQ low cut. White noise riser routed INTO the bass bus to be crunched together. Phase-distorted, low-cut one-shot tucked behind.

## Main gun
Serum: wavetable + sub + **band-pass filter**; LFO1 → WT pos, level, cutoff, sub level, high EQ gain; Serum distortion; **LFO → master pitch** (fast envelope → transient "laser"). Post: **Disperser → Multipass ("the oddprophet method") → EQ → Fruity Balance** (automated to kill tails on fills).

## "Big gun snare" (snare→gun, used every track)
**Transient shaper (extreme) → Frequency shifter → 1–3 Dispersers → GClip (soft mode) → EQ low cut.** Soft not hard because it's never the main bass.

## Sub
Fat sine + noise osc, distortion "crazy"; LFO1 (fast, envelope mode) → master tune = transient pitch drop; LFO2 slower pitch movement. Post: saturation (dynamics + DC filter off), EQ cut mud, slight LF boost.

## "Awful" sustain
Two sines, one synced (level down), FM; distortion. Post: **Freq shifter → Multipass (automated in B half for screech) → Saturator → Multipass (phase distortion) → Disperser → OTT → EQ → Fruity Balance.**

## Alien bass
Fruity Fast Distortion → (Disperser off) → Multipass → **stereo width to 0 (mono) because convolvers are chaotic in stereo** → OTT → Dimension Expander (re-adds width) → Parametric EQ → Balance. Automate convolver mix with the bass.

## Resampled drop layer
Disperser → Disperser → OTT → Multipass → Freq shifter → Dimension Expander → EQ.

## Fills ("mud pies")
Resample whole drop into Edison, record into second Edison while abusing tape-stop.

## Master
GClip + Maximus on premaster.
