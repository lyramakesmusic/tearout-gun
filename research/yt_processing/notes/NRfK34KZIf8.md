## Routine 1 (Serum 2)
1. Osc A sine (WT pos 2), at C0/D0. Osc B on, level 0, **PD (phase distortion/PM) from B at ~50%** into A. Osc A level 0 then LFO1 → level (amp shape).
2. Osc B spectral wavetables, scrub tables + WT position; LFO1 → WT position (slight; too much = gargly).
3. Compressor first, gain ~9 [dB].
4. Osc C, PD from C 20–50%.
5. LFO rates: bar, 1/2, 1/4, 1/8; triplets 1/8T and 1/4T common. Random turned to 0 for repeatability.
6. Filter: High Notch 12 (also band-notch, BP, notch, HP, LP). LFO → cutoff ~21–30%; LFO inverted → notch frequency; a bit of resonance + drive.
7. Phaser mix 60→35%; Hyper/Dimension ~30% for width (sides added late; mono first).
8. Level meter: raw peak -14 → target ~-5 [dBFS] before loud rack.
**Loud rack** (Ableton):
- OTT: 60 dB [likely output gain/"time"? — stated "60 dB 81%"; amount 81%, varied 20–50% per sound].
- Saturator 5 dB drive, dry/wet 100%.
- OTT #2: "6 dB 76%".
- Saturator #2.
- EQ Eight (boost highs or lows as needed).
- (Compressor off.)
- Clipper at end (with gain).
Levels: -11 before → -8 after rack; then OTT output +12, amount 30% → ~-6 "clean gain"; further OTT (VST) push → ~-4/-3. "Three OTTs ... 69%". OTT depth = dry/wet.
## Routine 2 (comb)
Sine + osc B PD; filter BP with resonance + drive, LFO on cutoff and inverted on freq → vowels/formants. FX: compressor, Hyper, Distortion, FX filter = "Misc Combs" (resonance + drive up; static spot chosen, low-cutoff side gives formant-like peaks; automating comb cutoff "doesn't work as well"). Macro to sweep between known-good comb spots.
